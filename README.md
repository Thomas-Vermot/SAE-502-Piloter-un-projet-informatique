SAE 502 Piloter un projet informatique

Objectif de la SAE : Réaliser une infrastructure d'hôpital de campagne à partir de zéro.
Prérequis : 
- Création de VLAN avec ACL,
- Utilisation de pare-feu,
- Services DHCP/DNS/AD,
- Utilisation d'une base de données,
- Création d'une application métier,
- Utilisation de MQTT pour l'IoT,
- Capteur de badges RFID
